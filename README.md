# Cake Quest

Интерактивный русскоязычный онлайн-квест ко Дню матери. Дети помогают поварёнку найти ингредиенты, взбивают крем, собирают клубничный пазл и получают подсказку, где искать настоящий сюрприз в группе.

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не нужны; аудиофайлы хранятся в `assets/` и загружаются с сайта вместе с игрой.

## Подготовка подсказки для группы

На стартовом экране раскройте раздел «Воспитателю: настроить подсказку», введите место, где спрятаны открытки или поделки, и нажмите «Сохранить подсказку». Она сохранится в локальном хранилище этого браузера и появится на финальном экране. Перед занятием настройте её на том устройстве и в том браузере, на котором будете проводить квест.

## Публикация

Сайт опубликован на GitHub Pages: <https://luwili.github.io/cake-quest-final/>. Каждый push в ветку `main` автоматически публикует новую версию через GitHub Actions (`.github/workflows/deploy.yml`).

## Звук и атрибуция

- Голос куриц — [Alys, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Chickens_demanding_food.ogg), общественное достояние.
- Музыка для танца — [Happy Beat, burabotti](https://opengameart.org/content/happy-beat), CC0.
- Аплодисменты — [Applause i, Thore, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Applause_i.ogg), общественное достояние.

Аудиодорожки подготовлены для браузерного воспроизведения и включены в репозиторий, чтобы игра не зависела от доступности сторонних аудиохостингов.
